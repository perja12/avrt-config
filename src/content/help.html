Introduction

The __AP510_APP_NAME__ can be used to program the SainSonic AP510 and AVRT5 APRS devices. This progam uses Web Serial and the browser have to support this standard. Most modern browsers supports this by now.

Important: this software has been tested on a limited number of trackers. Writing an incorrect configuration, interrupting a write, or using incompatible firmware may cause the tracker to malfunction. Keep a backup of the original configuration before writing changes. And proceed on your own risk.

AP510 tracker configuration

The Configure workspace contains the main functionality. This is where one can read the settings from the tracker, change them and write them back. The tracker settings are grouped as follows:

  • APRS: here you will find most of the APRS related settings like callsign, SSID, the APRS symbol to use and so on.
  • Beaconing: this groups shows the different options for when or how often to transmit an APRS packet
  • Radio: here you will find settings like TX frequency, TX power, squelch etc.
  • Device: here you can control device settings like enabling or disabling the LED, enable/disable beep when sending APRS packets etc.

How to connect the tracker

Important: do not use a regular USB cable! The mini USB connector in the tracker is using UART.

Use the programming cable that came with the device and connect the tracker with power off. Or you can also create your own cable or buy one. That is a good option if your OS doesn't recognize the serial driver in the cable.

  1. Click the Connect button and choose the serial port that corresponds to the device. If you can't identify the port: try to unplug the cable, click connect and make a note of the available options. Then re-insert the cable and click Connect again. Then you should hopefully be able to identify the correct port.
  2. Next click the Read button to read the configuration from the device. Now you must power on the tracker by keeping the button pressed until the tracker beeps. The program then reads the configuration.
  3. Change the values as you want and click Write to store the configuration in the tracker.
  4. Click Disconnect to disconnect from the serial port.
That should be it if everything went fine.

How to use templates

Templates let you apply a consistent set of settings to multiple trackers. Values such as callsign and SSID can be kept from each individual tracker.

  1. Start by configuring a tracker with the desired settings in the Configure panel. Then press the Save as template... button.
  2. Choose the fields that should be kept for each tracker. For example if callsign and SSID can be marked they will not be set by the template, but taken from each tracker.
  3. Save the template with the desired name. The template will be saved in the web browser, but you can later export it from Manage Templates.
  4. Then go to the Templates panel, select the newly saved template and use the Read and Apply template buttons program the trackers one by one.
